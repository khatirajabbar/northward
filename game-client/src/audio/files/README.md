# The game's sounds

Every `.mp3` in this folder is played by the game, matched by its name to a
sound in `../sounds.js`. `tools/audio.mjs` makes them with ElevenLabs; a file
made somewhere else just needs saving here under the right name:

- `music-title.mp3` — the title screen and the morning
- `music-forest.mp3` — the walk through the forest
- `music-ending.mp3` — sitting by the fire, and the credits

A sound with no file here is simply silent.
